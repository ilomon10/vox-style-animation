# Why railroads gave America time zones
// Example project of the framework. Every claim is sourced in RESEARCH.md.
// Build it: npm run example  (= tools/py tools/examples/build_example.py example-time-zones)

[BEAT recipe=ColdOpenYear anchor="Before"]
Before eighteen eighty-three, towns across America kept their own time.
[BEAT recipe=KeywordCut anchor="Noon"]
*Noon* came when the sun stood highest, so noon in New York was not noon in Philadelphia.

[PAUSE 0.5]

[BEAT recipe=GiantWordCard anchor="railroads"]
For the railroads, that was a problem: by one count, they ran on *fifty-six* different times.
[BEAT recipe=MapRoute anchor="So"]
So on November eighteenth, eighteen eighty-three, they split the country into *four* time zones.

[PAUSE 0.5]

[BEAT recipe=KeywordCut anchor="year"]
A year later, delegates in Washington voted to count the world's longitude from *Greenwich*.
[BEAT recipe=EndCard anchor="Congress"]
Congress only made the zones law in nineteen eighteen.
