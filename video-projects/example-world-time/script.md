# How the world agreed on time
// Example project of the framework: the block gallery in examples/ was rendered from it.
// Every claim is sourced in RESEARCH.md. Build it: tools/py tools/examples/build_example.py example-world-time

[BEAT recipe=PhotoCollageUnfold anchor="Towns"]
Towns used to set their clocks by the *sun*.
So how did the whole world end up on one clock?

[PAUSE 3.4]

[BEAT recipe=MontageCrane anchor="By"]
By the eighteen seventies, *railroads* and *telegraph* lines crossed the whole continent.
[BEAT recipe=NameCardInterview anchor="Railway"]
Railway engineer Sandford Fleming pushed for one system for the whole world.
[BEAT recipe=DataChart anchor="His"]
His plan: *twenty-four* time zones, one for every hour.

[PAUSE 0.4]

[BEAT recipe=DocumentHighlight anchor="In"]
In eighteen eighty-three, American railroads adopted four zones: Pacific, Mountain, Central and Eastern.
[BEAT recipe=QuoteCard anchor="A"]
A year later, delegates in Washington resolved to adopt a *single* prime meridian for all nations.
[BEAT recipe=DataChart anchor="Greenwich"]
Greenwich won the vote: twenty-two to one, with two abstaining.

[PAUSE 0.4]

[BEAT recipe=FootageClip anchor="The"]
The conference itself never created time zones.
Today, the world's zones are set as offsets from Coordinated Universal Time.
[BEAT recipe=EndCard anchor="That's"]
That's how the world agreed on time.
